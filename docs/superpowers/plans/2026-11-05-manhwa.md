# YitVerse Manhwa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Cambiar el producto a un servicio funcional de lectura de manhwas.
**Architecture:** React consume catálogo, capítulos y estado personal por cookie de una API SQLite. Las páginas e ilustraciones se sirven como archivos locales.
**Tech Stack:** React 19, TypeScript, Vite, Node24, SQLite, Playwright.
**Spec:** `docs/superpowers/specs/2026-11-05-manhwa-design.md`.

## Global Constraints

- Español, aspecto oscuro con violeta, historias originales de muestra.
- Aislamiento de biblioteca/progreso por navegador, no cuentas ficticias.
- Conservar la API/datos anteriores; sin publicar ni subir a GitHub.
- Exactamente seis series, tres capítulos/serie, tres páginas/capítulo, rutas de la especificación.

## Review Focus

- Progreso cruzado entre series y entre visitantes: rechazar cruces y mantener separación.
- Cambio de capítulo y scroll: no guardar la página del capítulo anterior en el nuevo.
- Favoritos y búsquedas con acentos: coherencia tras recargar y filtros vacíos claros.
- Lector móvil y teclado: controles accesibles y sin desbordamiento.
- Enlaces antiguos o inexistentes: fallback seguro sin bloquear toda la aplicación.
