# YitVerse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Entregar un espacio personal funcional de proyectos, tareas y recursos.

**Architecture:** Frontend React consume una API Node del mismo origen mediante proxy Vite en desarrollo. SQLite conserva los datos y producción sirve `dist/`.

**Tech Stack:** Node 24, React 19, TypeScript, Vite, SQLite, node:test, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-05-yitverse-design.md`

## Global Constraints

- Español; aplicación personal sin autenticación, backend en 127.0.0.1 por defecto.
- Respetar el contrato de la especificación y guardar datos en `.data/` ignorado por Git.
- No publicar el entorno, no hacer push, no restaurar el antiguo README.
- Búsqueda, filtros y métricas usan datos reales. Los ejemplos iniciales se identifican.

## Review Focus

- Títulos vacíos y límites de longitud: rechazo claro sin escritura.
- URLs ejecutables: aceptar únicamente http/https.
- Proyecto eliminado: ninguna tarea huérfana ni fallo de interfaz.
- Error de red: informar sin mostrar una mutación como guardada.
- Pantalla estrecha y teclado: navegación, diálogos y formularios utilizables.
